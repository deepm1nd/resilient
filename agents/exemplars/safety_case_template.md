# Safety Case Template (GSN Style)

## 1. Goal (G1): The system is safe for its intended use.
- **Context:** [Operational environment, assumptions]
- **Strategy (S1):** Argument based on compliance with [Standard] and mitigation of all identified hazards.

## 2. Sub-Goals
- **G2:** All hazards identified in HARA have been addressed by safety goals.
- **G3:** All safety goals are met by functional and technical requirements.
- **G4:** All requirements are correctly implemented.
- **G5:** All requirements are verified through testing.

## 3. Evidence (Solutions)
- **E1:** HARA Report (`HARA_Report.md`)
- **E2:** Traceability Matrix (`Traceability_Matrix.md`)
- **E3:** Test Summary Report (`System_Test_Report.md`)
- **E4:** Tool Qualification Report (`Tool_Qualification.md`)
